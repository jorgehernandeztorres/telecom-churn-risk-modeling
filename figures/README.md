# Figures from the verified original-data execution

These five PNG files are extracted from the executed notebook outputs against the original UCI Iranian Churn dataset. They are not generated from synthetic or test-fixture data. Re-running the notebook may overwrite them with newly computed equivalents.

- `development_eda.png` — descriptive patterns on development data only
- `holdout_model_diagnostics.png` — ROC, precision-recall and thresholded confusion matrix
- `holdout_cumulative_capture.png` — cumulative observed churn capture against review capacity
- `holdout_calibration.png` — grouped observed frequencies vs. predicted probabilities
- `holdout_permutation_importance.png` — descriptive test-set permutation importance

All charts are observational and do not establish the causal impact of an intervention.
