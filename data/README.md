# Download the original dataset

From the repository root, execute:

```bash
python scripts/download_data.py
```

This retrieves the **UCI Iranian Churn** original CSV via the official UCI dataset archive into `data/iranian_churn.csv`. Alternatively, download the original CSV from https://archive.ics.uci.edu/dataset/563/iranian+churn+dataset and save it under the same filename.

The raw file is intentionally omitted from this repository to keep the original dataset's source and attribution explicit. UCI distributes the data under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), DOI https://doi.org/10.24432/C5JW3Z.
